# COS — Knowledge OS

## What this vault is
Personal knowledge operating system — built on PARA + Maps of Content, with AI-first note conventions.

## Folder map (PARA)
| Folder | Purpose |
|--------|---------|
| `00-Inbox/` | Capture fast — process weekly |
| `01-Daily/` | Morning plans (`morning-set/`) |
| `02-Projects/` | Active work with goal + deadline |
| `03-Areas/` | Ongoing responsibilities (no deadline) |
| `04-Resources/` | Reference by topic |
| `05-Knowledge/` | Consolidated frameworks + People CRM + Templates |
| `06-Wiki/` | Entities, concepts, decisions, day logs, week logs |
| `07-Maps/` | Maps of Content — index notes linking related notes |
| `08-Archive/` | Completed, inactive, paused |
| `09-agents/` | Agent configs and automation scripts |

## Key files
- `07-Maps/Home.md` — vault entry point
- `06-Wiki/README.md` — daily tracking system docs
- `06-Wiki/day_logs/YYYY-MM-DD.md` — daily logs (plan + track + review)
- `06-Wiki/week_logs/weekly-YYYY-MM-DD.md` — weekly synthesis
- `05-Knowledge/Templates/` — note templates (daily, morning, evening)
- `02-Projects/<active-project>/` — current active project
- `SOUL.md` — who you are, values, constraints
- `CRITICAL_FACTS.md` — always-loaded key facts

## Session skills
| Skill | When |
|-------|------|
| `/session-context` | Start of every session |
| `/plan` | Daily work — pick next task |
| `/wrap-up` | End of session |
| `/new-note` | Capture a new permanent note |

## Hard rules
- Every note goes in the right PARA folder — not the root
- Inbox is processed at least once/week
- Maps link to notes; notes link back to their Map
- Archive rather than delete
